# 接线与调试

## 1. 主控引脚表

适用经典ESP32-WROOM-32开发板，以下是GPIO编号，不是板上的顺序脚号。

| 器件 | 器件端 | ESP32端 | 说明 |
|---|---|---|---|
| DHT22 | VCC / GND / DATA | 3V3 / GND / GPIO4 | DATA用4.7kΩ上拉到3V3；裸DHT22通常4脚中第3脚NC，核对实物 |
| BH1750 | VCC / GND / SDA / SCL | 3V3 / GND / GPIO21 / GPIO22 | ADDR接GND/默认，I²C地址0x23 |
| 电容土壤探头 | VCC / GND / AO | 3V3 / GND / GPIO34 | AO到GND加1MΩ；GPIO34为ADC1，避免经典ESP32 ADC2与Wi-Fi的资源冲突 |
| 浮球 | 两根干接点线 | GPIO27 / GND | 水够时闭合；固件INPUT_PULLUP，开路即缺水 |
| 水泵继电器驱动 | 基极电阻输入 | GPIO25 | 默认高电平开启 |
| 风扇继电器驱动 | 基极电阻输入 | GPIO26 | 默认高电平开启 |
| 灯继电器驱动 | 基极电阻输入 | GPIO33 | 默认高电平开启 |

所有传感器信号≤3.3V，特别是廉价模拟土壤模块，通电后先用万用表验证。ADC原始值不是绝对含水量，ESP32 ADC也存在非线性。

## 2. 每一路继电器的分立驱动（默认）

```text
ESP32 GPIO --330Ω-- B  PN2222A
                    E -------- GND
                    C -------- 继电器线圈负端
GPIO侧基极节点 --100kΩ-- GND
5V ---------------------------- 继电器线圈正端

1N4007跨接在线圈两端：带色环的K端接5V，A端接集电极。
ESP32 GND、DC-DC GND、12V负端共地。

12V正端 -- 分路保险 -- 继电器 COM
继电器 NO ----------- 负载正端
负载负端 ------------ 12V负端
NC不接。
```

三个通道分别使用GPIO25/26/33。二极管不能接反，否则相当于短路电源。PN2222A脚序按采购厂家的数据手册确认；不同封装/厂家的脚序可能不同。继电器线圈约70–80mA时，上述330Ω电阻提供约7mA基极电流；若改用不同线圈，重新核算驱动能力。

有刷直流水泵两端另并一只续流二极管：色环K端接水泵正端，A端接负端。继电器触点要按**直流负载和启动电流**选型。全系统只使用低压直流负载，灯具为带驱动的12V输入成品。

继电器可能粘连、水管可能虹吸；软件停泵无法解决这些故障。持续无人值守前增加流量监测、独立硬件限时/断水，并验证断电停止出水。

## 3. 两块板的供电

```text
12V适配器 -> 总保险 -> 12V负载分路
                     -> DC-DC 5V -> 主控5V/VIN、ESP32-CAM 5V、3只继电器线圈
主控3V3 -> DHT22、BH1750、土壤探头
```

DC-DC调好5.0V再接板子。两块板使用星形供电回路，电机走独立电源线，远离模拟信号。USB调试期间避免USB和外部5V直接互相回灌，按开发板电源原理图处理或断开外部5V。

## 4. ESP32-CAM下载

优先使用ESP32-CAM-MB USB底板；若使用USB-TTL，逻辑电平必须3.3V，TX接U0R、RX接U0T、GND共地，由稳定的独立5V电源给相机供电。不要让USB-TTL的5V TX信号进入ESP32。

下载时GPIO0接GND并复位，上传完成后断开GPIO0与GND，再复位进入拍照程序。正常运行时GPIO0用于相机XCLK，不外接按键。本固件关闭GPIO4闪光灯，不启用SD卡。

## 5. 土壤标定

1. 先断开水泵负载，串口115200查看 `raw=...`。
2. 将探头按实际埋深插入干燥的目标基质，稳定后记录原始值，填入 `SOIL_DRY_RAW`。
3. 将同一基质浇透，充分排水并稳定后记录原始值，填入 `SOIL_WET_RAW`。不要把探头电路板泡水。
4. 重新编译、刷机。相对湿度计算为 `(dry-raw)/(dry-wet)*100`，截断在0–100%，不代表体积含水率。
5. 装好1MΩ下拉后标定；干湿原始值至少差100。正常读数应远离0和4095，否则检查供电/量程，不能通过忽略故障来启动水泵。

## 6. 首次带电检查顺序

1. 先只接ESP32和传感器，确认控制台数据、水位开关正反逻辑与实际一致。
2. 接驱动和继电器，但不接负载；上电/复位/Wi-Fi断线时不应产生意外吸合。
3. 逐路手动开/关，确认输出引脚与实际设备对应；网页“指令已保存”不是执行确认，要看遥测和实物。
4. 水泵接入带水容器，测试缺水立即停、土壤断线停、单次限时、冷却期无法启动。
5. 完成标定，调整阈值，最后启用自动控制。上电默认策略自动关闭；启用后会存入NVS，后续重启恢复已保存策略，并先经历水泵冷却期。
