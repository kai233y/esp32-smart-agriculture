# 器件清单（单区原型，1套）

主控与摄像头使用**两块板**：主控为 ESP32-WROOM-32 DevKit，摄像头为 AI Thinker ESP32-CAM。两块板通过同一 2.4 GHz Wi-Fi 连接服务器，不直接连接彼此的 GPIO。

本清单不包含销售报价，实际价格、模块电路和供电标识请向商家核对。

## 可选替代与扩展

- 若不想焊接分立驱动，可购买**经过确认的3.3V输入兼容、5V线圈、带驱动和续流的继电器模块**，替代继电器、NPN、330Ω、100kΩ及线圈二极管。测量IN端和确认原理图，不能让5V进入GPIO；若为低电平触发，把 `RELAY_ACTIVE_LOW` 改为 `true`，并配置可靠的3.3V上拉来保证启动关闭。
- 工业温室建议改用SHT31/SHT35、工业水分探头、流量计、接触器和独立硬件断水保护；这些扩展不在当前源码驱动范围内。
- 小虫识别取决于像素和距离。OV2640远景不能保证识别蚜虫/粉虱，建议近距离定点拍叶背、调焦、漫射补光；更大区域需要多相机或巡检装置。

## 供电核算示例

若水泵1A、风扇0.3A、灯0.8A，12V负载约2.1A；再加5V侧换算、电源损耗和电机启动余量。因此12V 5A只能作为这组小负载的初选，实际选型以厂家数据和实测峰值为准。两块ESP32、相机和继电器由5V DC-DC供电，传感器由主控3.3V供电。继电器线圈、电机等不能从ESP32的3.3V引脚取电。
